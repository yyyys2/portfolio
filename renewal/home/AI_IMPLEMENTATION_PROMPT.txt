첨부된 HOME_IMPLEMENTATION_GUIDE.md와 reference-images/home-final-approved.png를 기준으로 기존 포트폴리오의 Home 페이지를 구현해줘.

먼저 기존 코드베이스의 프레임워크, 라우팅, 스타일 방식, 디자인 토큰, 공통 Header/Footer, 애니메이션 라이브러리, 프로젝트 데이터 구조를 확인하고 기존 방식을 우선 사용해. 요청 범위는 Home 페이지이며 다른 페이지와 사용자의 기존 변경사항은 수정하지 마. 시안 PNG를 화면에 그대로 삽입하지 말고 React + TypeScript 컴포넌트, CSS, SVG로 재현해.

화면은 단순한 왼쪽 텍스트/오른쪽 이미지 50:50 구조로 만들지 마. 12열 기준에서 텍스트와 Featured Project 패널의 시각 영역이 일부 겹치는 비대칭 레이아웃으로 구성하되 글자를 가리면 안 돼. Home 문구와 디자인 토큰은 가이드의 고정 콘텐츠와 값을 사용하고, 모든 한글은 Pretendard 계열 산세리프로 구현해.

Hero 고정 문구는 `Frontend` / `Developer.`의 2줄 제목과 `화면은 사용하기 편하게, 코드는 고치기 쉽게.`라는 설명이야. CTA는 `프로젝트 보기 →`로 표시해. 가장 중요한 시각 요구사항은 `Developer.`의 실제 마지막 온점과 Featured Project 패널을 잇는 연결선이야. 온점 옆에 별도의 시작 원을 추가하지 말고, 온점 span의 오른쪽 중앙에서 SVG path가 간격 없이 시작되게 해. 패널의 왼쪽 경계에는 작은 종료 노드 하나만 둬. ResizeObserver로 초기/리사이즈/폰트 로딩 시 좌표를 갱신하고 매 프레임 DOM 좌표를 읽지 마.

오른쪽 Featured Project 패널은 transform 기반으로 천천히 떠 있는 효과를 적용해. 이동 범위는 x 약 2px, y 약 6~8px, 한 주기는 약 5.2초로 제한해. 온점과 선 시작점은 고정하고, 선의 종료점은 패널과 동일한 motion value를 사용해서 정확히 따라가야 해. 선 중간 제어점은 이동량의 약 35~45%만 반영해서 약한 탄성만 표현하고 선 전체를 독립적으로 흔들지 마. 연결선을 먼저 그린 후 floating을 시작해.

오른쪽 검색 영역은 장식이 아니라 실제 프로젝트 검색 기능이야. `PROJECT SEARCH` label, `프로젝트명 또는 기술 검색` placeholder, `React`, `WebOS`, `AI Agent` 추천 검색어 버튼을 항상 노출해. 프로젝트명·설명·기능 키워드·기술 스택에서 부분 일치로 검색하고 결과는 최대 3개만 보여줘. 검색 결과나 추천어를 선택하면 Featured 카드와 `FEATURED nn / 04`를 함께 갱신해. `Cmd+K`/`Ctrl+K`, ArrowUp/ArrowDown, Enter, Escape를 지원하고 combobox/listbox의 접근 가능한 관계와 `aria-live` 안내를 구현해. 자동 타이핑이나 반복 pulse는 사용하지 말고, 최초 1회의 약한 focus cue만 허용해.

CTA, Case Study, 검색 추천어, 결과 항목과 프로젝트 전환 버튼은 실제 button/a 요소로 구현하고 키보드 조작과 focus-visible을 지원해. hover/focus 중에는 floating을 부드럽게 멈춰 조작을 방해하지 않게 해. prefers-reduced-motion에서는 진입 모션, floating, 자동 전환을 정지하고 정적인 최종 상태를 보여줘. 모바일에서는 연결선과 floating, overlap을 제거하고 텍스트→CTA→패널 순서의 단일 열로 변경하며 `⌘ K` 힌트 대신 명시적인 `검색` affordance를 제공해.

새 라이브러리는 꼭 필요한 경우에만 추가하고, 기존에 Framer Motion이 있다면 가이드의 공유 motion value 방식을 프로젝트 버전에 맞게 사용해. 프로젝트 데이터와 성과 수치를 임의로 만들지 마.

구현 후 typecheck, lint, build를 실행하고 360/768/1024/1440px, 검색 및 추천 검색어, 검색 결과 0/1/3개 상태, 키보드 조작, reduced-motion, resize 시 연결선 좌표, 패널 floating 중 선 끝점 동기화를 확인해. 마지막 응답에는 변경 파일, 핵심 구현 내용, 검증 결과, 남은 콘텐츠 교체 항목을 요약해.
