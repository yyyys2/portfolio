# Portfolio About 구현 전달 패키지

## 파일 구성

- `ABOUT_IMPLEMENTATION_GUIDE.md`: 레이아웃, 문구, 연결선, 인터랙티브 데모, 반응형, 접근성 및 완료 조건
- `AI_IMPLEMENTATION_PROMPT.txt`: 코드 구현 AI에게 그대로 전달할 최종 명령문
- `reference-images/about-final-approved.png`: 확정한 About 화면 참고 이미지

## 전달 방법

코드 작업을 수행할 AI에게 이 폴더 전체를 전달하고 `AI_IMPLEMENTATION_PROMPT.txt`의 내용을 실행하도록 요청한다.

참고 이미지는 시각 기준이며 이미지 자체를 웹페이지에 삽입하는 용도가 아니다. 기존 Home에서 사용하는 Header, 디자인 토큰, 온점 연결선, floating 패널 구현을 우선 재사용한다.
