첨부된 `ABOUT_IMPLEMENTATION_GUIDE.md`와 `reference-images/about-final-approved.png`를 기준으로 기존 포트폴리오의 About 페이지를 구현해줘.

먼저 기존 코드베이스의 프레임워크, 라우팅, 스타일 방식, 디자인 토큰, 공통 Header/Footer, Home의 온점 연결선과 floating 패널 구현, 애니메이션 라이브러리를 확인해. 기존 방식을 우선 사용하고 요청 범위는 About 페이지로 제한해. 다른 페이지와 사용자의 기존 변경사항은 수정하지 마. 시안 PNG를 화면에 그대로 삽입하지 말고 React + TypeScript 컴포넌트, CSS, SVG로 재현해.

About의 고정 문구는 가이드와 정확히 일치시켜. Hero 제목은 `화면을 만드는` / `방식.` 두 줄이며, 설명은 `React와 TypeScript를 중심으로 웹 서비스를 개발해왔습니다.`와 `신규 구축부터 운영·유지보수, Svelte 기반 webOS 프로젝트를 경험했습니다.` 두 줄이야. 한글은 모두 Pretendard 계열 산세리프를 사용하고 명조체나 필기체를 사용하지 마.

Hero는 단순한 왼쪽 텍스트/오른쪽 이미지 50:50 구조로 만들지 마. 텍스트와 Component Playground 패널의 시각 영역이 일부 겹치는 비대칭 레이아웃으로 구현하되 글자를 가리면 안 돼. 가장 중요한 시각 요구사항은 `방식.`의 실제 마지막 온점과 패널을 잇는 연결선이야. 온점 옆에 별도의 시작 원을 추가하지 말고 온점 span의 오른쪽 중앙에서 SVG path가 간격 없이 시작되게 해. 패널 왼쪽 경계에는 작은 종료 node 하나만 둬. ResizeObserver로 초기, resize, 폰트 로딩 시 좌표를 갱신하고 animation frame마다 DOM 위치를 읽지 마.

오른쪽 패널은 이미지가 아니라 실제 동작하는 Component Playground야. 상단에 `● INTERACTIVE DEMO`, 오른쪽에 `상태를 선택하면 UI와 코드가 바뀝니다.`를 표시하고 DEFAULT, FOCUS, DONE tab을 실제 button으로 구현해. 상태를 선택하면 Preview와 Code가 함께 바뀌어야 해. DEFAULT는 기본 버튼, FOCUS는 명확한 focus-visible 상태, DONE은 체크 아이콘과 `완료되었습니다` 상태를 보여줘. tablist/tab 접근성 패턴을 적용하고 Left/Right, Home/End 키보드 조작과 focus-visible을 지원해. 처음 진입 시 `DEFAULT → FOCUS → DEFAULT` 데모를 한 번만 실행할 수 있지만 사용자가 조작하면 즉시 중단하고 반복 자동 전환은 금지해.

왼쪽 component tree는 `<App>`, `<Header />`, `<Main>`, `<Search />`, `<Button />`, `<Card />`, `<Footer />`를 보여주고 `<Button />`을 선택 상태로 표시해. 다른 항목의 기능을 구현하지 않을 거라면 clickable control처럼 만들지 마. Code 영역은 `pre > code`로 구현하고 사용자 입력을 실행하지 마.

패널은 transform 기반으로 x 약 1~2px, y 약 4~6px, 한 주기 5.8~6.2초 범위에서 Home보다 잔잔하게 떠 있어야 해. 온점과 선 시작점은 고정하고 선 종료점은 패널과 같은 motion value를 사용해 정확히 따라가게 해. 선 중간 제어점은 이동량의 35~40%만 반영하고 선 전체를 독립적으로 흔들지 마. 연결선을 먼저 그린 후 floating을 시작하며 panel hover/focus 중에는 현재 위치에서 부드럽게 멈춰.

Core Strengths는 둥근 카드가 아니라 구분선을 사용한 하나의 가로 band로 구현해. 내용은 `제품 UI`, `프론트엔드 구조`, `접근성과 인터랙션`과 가이드의 고정 설명을 사용해. 하단은 Contact가 아니라 `EXPERIENCE / 담당 업무와 프로젝트별 경험 / 경력 보기 →` CTA이며 실제 Experience route로 연결해.

`prefers-reduced-motion`에서는 진입 모션, 최초 상태 데모, floating, connector draw animation을 모두 멈추고 정적인 최종 상태를 보여줘. 모바일에서는 overlap, connector, floating, panel tilt를 제거하고 Hero copy → Component Playground → Core Strengths → Experience CTA 단일 열로 변경해. tab과 CTA는 최소 44×44px 터치 영역을 확보해.

새 라이브러리는 꼭 필요한 경우에만 추가하고, 기존 Home에 connector hook이나 motion value 공유 방식이 있다면 일반화해 재사용해. 다만 About 레이아웃을 Home과 똑같이 만들지는 마. 경력, 회사, 성과, 프로젝트 데이터를 임의로 생성하지 마.

구현 후 typecheck, lint, build를 실행하고 360/768/1024/1440px, DEFAULT/FOCUS/DONE 상태, 마우스·키보드 조작, 최초 데모 중 사용자 개입, reduced-motion, resize 시 연결선 좌표, floating 중 선 끝점 동기화를 확인해. 마지막 응답에는 변경 파일, 핵심 구현 내용, 검증 결과, 남은 실제 route 또는 콘텐츠 교체 항목을 요약해.
