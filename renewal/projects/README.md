# Portfolio Projects 구현 전달 패키지

## 파일 구성

- `PROJECTS_IMPLEMENTATION_GUIDE.md`: 목록·상세 상태, Preview 전환, 연결선, 반응형, 접근성 및 공개용 재구성 화면 기준
- `AI_IMPLEMENTATION_PROMPT.txt`: 코드 구현 AI에게 그대로 전달할 최종 명령문
- `reference-images/projects-list-final.png`: 프로젝트 기본 목록 상태
- `reference-images/projects-expanded-final.png`: AI Agent 상세 펼침 상태

## 전달 방법

코드 구현 AI에게 폴더 전체를 전달하고 `AI_IMPLEMENTATION_PROMPT.txt`의 내용을 실행하도록 요청한다.

두 PNG는 시각 참고용이다. 페이지에 이미지 한 장으로 삽입하지 말고 실제 HTML, React 컴포넌트, CSS, SVG로 구현한다. 프로젝트 화면 이미지는 보안 정보를 제거한 공개용 재구성 자료로 취급한다.
