# 💼 Frontend Portfolio

> Soft on the outside, reliable on the inside.  
> 실서비스 운영 경험을 기반으로 안정적인 UI를 설계하는 프론트엔드 개발자의 포트폴리오입니다.

---

## 🧑‍💻 About

6~7년차 프론트엔드 개발자로서, 실제 서비스 환경에서 다뤄온 구조 설계와 운영 경험을 기반으로 제작한 포트폴리오입니다.

- 경력: 6~7년차 프론트엔드 개발자
- 핵심 도메인:
  - WebOS / 스마트 디스플레이 기반 디바이스 환경
  - Enterprise / B2B 관리자 플랫폼
  - 금융 / 공공 시스템
- 강조 포인트:
  - 상태 정확성 및 예외 케이스 대응
  - 운영 가능한 UI 설계
  - 디바이스 환경 제약 대응 경험

---

## 🎯 Project Goal

이 포트폴리오의 목표는 다음과 같습니다:

- 실서비스 운영 경험 강조
- 상태 정확성 및 예외 케이스 대응 능력 표현
- 구조적인 코드 설계 역량 전달
- 감성적이지만 가볍지 않은 디자인
- 도메인 기반 프로젝트 분류를 통한 전문성 표현
