# Portfolio Contact 구현 전달 패키지

## 파일 구성

- `CONTACT_IMPLEMENTATION_GUIDE.md`: 화면 구성, Contact panel 상태와 동작, 연결선, 반응형 및 접근성 사양
- `AI_IMPLEMENTATION_PROMPT.txt`: 코드 구현 AI에게 그대로 전달할 최종 명령문
- `reference-images/contact-final.png`: 중복 영역을 제거한 최종 Contact 참고 이미지

## 전달 방법

코드 구현 AI에게 이 폴더 전체를 전달하고 `AI_IMPLEMENTATION_PROMPT.txt`의 내용을 실행하도록 요청한다.

PNG는 시각 참고용이다. PNG 전체를 페이지에 삽입하지 말고 실제 HTML, React 컴포넌트, CSS, SVG로 재현한다. 이메일·GitHub·Resume 동작은 오른쪽 `QUICK CONTACT` 패널 한 곳에서만 제공하며, 참고 이미지에서 제거한 하단 링크 목록이나 추가 Contact 섹션을 다시 만들지 않는다.
