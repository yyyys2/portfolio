# Portfolio Home 구현 전달 패키지 v2

## 파일 구성

- `HOME_IMPLEMENTATION_GUIDE.md`: 레이아웃, 디자인 토큰, SVG 연결선, floating 동기화, 반응형, 접근성 및 완료 조건
- `AI_IMPLEMENTATION_PROMPT.txt`: 코드 구현 AI에게 그대로 전달할 최종 명령문
- `reference-images/home-final-approved.png`: 확정한 Home 화면 참고 이미지

## v2 반영 사항

- Hero 문구를 `Frontend Developer.`와 `화면은 사용하기 편하게, 코드는 고치기 쉽게.`로 변경
- 오른쪽 프로젝트 패널의 검색을 실제 기능으로 명시
- `PROJECT SEARCH` label, 추천 검색어, combobox 키보드 조작 및 모바일 affordance 추가
- 검색 결과 선택과 Featured 프로젝트/index 동기화 조건 추가

## 전달 방법

코드 작업을 수행할 AI에게 이 폴더 전체를 전달하고 `AI_IMPLEMENTATION_PROMPT.txt`의 내용을 실행하도록 요청한다.

참고 이미지는 시각 기준이며 이미지 자체를 웹페이지에 삽입하는 용도가 아니다.
